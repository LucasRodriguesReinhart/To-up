# HUD artwork

Created with the built-in imagegen tool, using the user's HUD image as a style reference.

Atlas: `hud-icons-atlas.png`
Roblox image: `rbxassetid://117093221263804`
Roblox uploaded texture: 1024 × 512; eight cells of 256 × 256.
Row 1: Shop, Pets, Inventory, Areas. Row 2: Trophy, Settings, Sound, Pickaxe.

Generation prompt:

Create one production-ready game UI sprite atlas, transparent PNG, 1536 by 768 pixels, exactly four columns by two rows of equal 384x384 cells. Reference image gives the desired thick black outline, richly shaded colorful painted 3D fantasy mobile-game icon style. This is a new atlas, not a screenshot. Eight isolated illustrated objects each centered wholly inside its own cell with at least 30px padding, identical apparent scale, transparent background across whole image. NO text, NO letters, NO circles or background plates, NO scene, NO labels. Row 1 left to right: a charming wooden shop stall with red-and-cream striped awning and gold coins; a dark purple kitten with big golden eyes and raised paw; a detailed brown leather adventurer backpack with gold buckle; a rolled parchment treasure map with a green pine tree, dotted route and red X. Row 2 left to right: a golden trophy with star; a silver-blue gear; a silver speaker with blue sound waves; a steel mining pickaxe with wooden handle and small purple crystal accents. Polished attractive game icons, dramatic highlights, crisp readable silhouettes at 64px, bold dark contour, match reference's illustration quality. All eight separated by transparent gutters and perfectly aligned to equal grid cell centers.

Final edit prompt:

Replace all checkerboard background with a flat opaque dark charcoal RGB(16,19,24), preserving all eight illustrated icons, their positions, the 4×2 grid, colors, bold outlines and details. No text; same 2:1 canvas.

Mining animation source: Toolbox asset 14052273882, Pickaxe Animation, by OneBitBanks. The six embedded R15 keyframes were copied into ReplicatedStorage.MiningSwing.Swing. Playback is triggered by server-validated mining hits. Imported tool gameplay scripts are disabled and are not used.
