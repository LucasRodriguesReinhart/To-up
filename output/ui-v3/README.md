# UI V3 — Anime Mining Simulator

Revisão de 17/09/2026 instalada no place 101959830085647.

O inventário usa personagem 3D completo, grade à esquerda e ficha compacta com ações à direita. A invocação apresenta três modelos reais em um palco, banners à esquerda e catálogo/chances à direita. O diário mostra duas linhas de recompensas no desktop. Os controles compartilham contornos pretos, faces planas, tipografia sem redução automática e layouts específicos para telas menores.

- `src/`: dez fontes correspondentes à versão verificada no Studio; sete alteradas nesta revisão.
- `before/`: exportação anterior às alterações V3.
- `qa/`: capturas reais do Play e registros de dimensões/legibilidade.
- `REFERENCE_SPEC.md`: comparação das referências fornecidas e pesquisa visual.
- `QA_RESULTS.md`: verificações realizadas e limites.
- `source-manifest.json`: hashes dos arquivos e comparação com a exportação anterior.

Backup adicional no Studio: `ServerStorage.BeforeUIV3_20260917_References` (fontes inertes com caminho original). Não é necessário importar o pacote para testar: a revisão já está instalada. Abra o Play e use H para inventário ou G para invocação; o diário fica no atalho lateral.

Salvar no Roblox preserva o projeto editável. Não foi solicitada uma publicação pública da experiência nesta revisão.
